# Glossary

| Term                                | Definition                                                                                                                                                                                                                                                                                     |
| :---------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **CHIPS (`Partitioned` Cookie)**    | Cookies Having Independent Partitioned State—used alongside `SameSite=None; Secure; HttpOnly` on `__Host-goc_session` so sessions work inside cross-site preview iframes while staying partitioned per top-level site.                                                                         |
| **Compaction**                      | Asynchronous maintenance task (Paid tier via `REPO_TASKS_QUEUE`, or manual via `/:owner/:repo/admin`) that merges multiple small active packfiles into fewer compacted packs and marks source packs `superseded` in `pack_catalog`.                                                            |
| **D1 (`DB`)**                       | Cloudflare's managed serverless SQLite database holding Gitra's 11 global relational tables (users, namespaces, repositories, metadata, PATs, and RBAC directory).                                                                                                                             |
| **Demo Mode**                       | Local development authentication mode active during `vite dev` when neither `AUTH_MODE=production` nor `ADMIN_PASSWORD` is configured; enables `admin`/`admin123`, `alex-dev`/`devuser123`, `/auth/demo-login`, and lazy demo repository seeding. Automatically disabled in production builds. |
| **Git Smart HTTP v2**               | Modern HTTP Git wire protocol (`Git-Protocol: version=2`) supporting `ls-refs` and `fetch` commands with `side-band-64k` streaming.                                                                                                                                                            |
| **Global Admin PAT**                | Personal Access Token with a row in `pat_global_grants`, mintable and usable only by active `admin` accounts to access repositories across all namespaces.                                                                                                                                     |
| **Islands (Client Islands)**        | Small browser-hydrated TypeScript modules under `src/client/islands/` loaded selectively per SSR page via `src/client/entrypoints.ts` to keep page weight minimal.                                                                                                                             |
| **`Limiter` (`SubrequestLimiter`)** | Per-request concurrency semaphore (`MAX_SIMULTANEOUS_CONNECTIONS = 6`) and soft subrequest budget (`DEFAULT_SUBREQUEST_BUDGET = 900`) in `src/worker/git/operations/limits.ts` protecting against Cloudflare's hard per-request limits.                                                        |
| **Namespace (`@slug`)**             | Top-level owner scope in Gitra URLs (`/:owner/:repo`), associated with a user, RBAC role (`admin`/`member`/`viewer`), optional profile metadata, and optional `.vibtools` profile repository.                                                                                                  |
| **`pack_catalog`**                  | Authoritative SQLite table inside each `RepoDurableObject` tracking active and superseded `.pack` files, tiers, sequence ranges, object counts, and byte sizes.                                                                                                                                |
| **PAT (Personal Access Token)**     | Credential formatted as `goc_<8-hex>_<32-base32>` (SHA-256 hashed in D1) used over HTTP Basic Auth for Git CLI operations (`pull` or `push`).                                                                                                                                                  |
| **`.refs` Sidecar**                 | Per-pack logical object-reference sidecar file (`do/<doId>/objects/pack/<name>.refs`) stored in R2 to accelerate `git-upload-pack` closure calculation without decompressing thousands of packed objects.                                                                                      |
| **Receive Lease**                   | Exclusive lock stored in `RepoDurableObject` acquired via `beginReceive()` and committed via `finalizeReceive()`. Guarantees single-writer consistency; concurrent pushes receive `503 Retry-After: 10`.                                                                                       |
| **`RepoDurableObject` (`REPO_DO`)** | Per-repository SQLite-backed Cloudflare Durable Object serving as the strongly consistent metadata authority for `refs`, `HEAD`, leases, and `pack_catalog`.                                                                                                                                   |
| **Single-Hop Boundary**             | Architectural rule restricting cross-runtime calls to one hop (`Worker → DO`, `Worker → R2`, or `DO → R2` in alarms) and prohibiting transitive `Worker → DO → R2` chains.                                                                                                                     |
| **`.vibtools`**                     | Reserved profile repository slug (`PROFILE_REPO_SLUG`) whose `profile/README.md` renders directly on the owning namespace's public profile page (`/:owner` or `/profile/admin`).                                                                                                               |
